# Windows 11 Web

A lightweight **Windows 11-inspired desktop** that runs completely in the browser.

Icons use a **Fluent-style** design inspired by the official [Windows 11 introduction](https://youtu.be/Uh9643c2P6k) — colorful, soft, modern SVG icons instead of emoji.

Works on old computers — you only need a modern browser (Chrome, Firefox, Edge).

## Apps included

| App | Description |
|-----|-------------|
| File Explorer | Simulated folders |
| Notepad | Text editor |
| **Paint** | Draw with mouse/touch |
| Calculator | Basic calculator |
| **Music Player** | Simple synth melodies |
| **Terminal** | Command-line simulator |
| **Sticky Notes** | Colorful notes |
| Browser | Simple web browser (iframe) |
| Settings | Theme & options |
| About | Info about this desktop |

## Features

- Desktop icons + Start menu (Fluent icons)
- Taskbar with open apps
- Draggable windows
- Minimize / Maximize / Close
- Lock screen
- Clock & system tray

## Important

This is **not real Windows 11**.  
It is a web simulation made with HTML, CSS and JavaScript.  
It cannot install real programs or access your computer files.

## How to run

### On any computer
1. Download / unzip the files
2. Open `index.html` in your browser

### On GitHub Pages
1. Create a new repository
2. Upload all files (`index.html`, `style.css`, `script.js`, `README.md`)
3. Go to **Settings → Pages**
4. Deploy from branch `main` (root folder)
5. Open the URL GitHub gives you
